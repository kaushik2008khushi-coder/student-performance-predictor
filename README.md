# Student Performance Predictor

This is a beginner-level Machine Learning project that predicts student performance.

## Project Description

The project predicts a student's final score using:

- Study Hours
- Attendance
- Previous Marks
- Assignment Score

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

## Machine Learning Algorithm

Linear Regression

## Project Goal

The goal of this project is to understand the basic Machine Learning workflow, including data preparation, model training, prediction, and evaluation.
